prod-deploy + verification interleaving. **~30 min total operator time.**

## What this session unlocked (recap for the merge-PR descriptions)

Today's chain of fixes addresses the **infrastructure-half-wired**
anti-pattern at six different layers:

| Layer | Half-wired thing | The wire (PR) |
|------|------------------|---------------|
| Deploy | CI validated migrations on ephemeral DBs but no prod-deploy step | `deploy.sh` + DEPLOYMENT.md (#186) |
| Schema | `auto_approval_calibration` migration shipped 2026-06-13 but never ran on prod | Operational recovery (today) |
| Pipeline | `daily_intel.sh` hardcoded `$HOME/.local/bin/uv` that broke when systemd context changed | `command -v uv` resolution (#187) |
| Content | Pipeline emitted `_captioned.mp4` paths under disabled-whisper conditions | PushToBacklog guard (#189) |
| Cleanup | Branch 1 + Branch 2 of `archive_orphan_drafts` had a gap for render-never-completed | Branch 2a (#190) |
| Cleanup | 119 sources kept being fetched despite 0% claim rate | FeedHealthTracker auto-disable (#193) |
| Scheduler | `_next_available_slot` didn't exclude the record being scheduled | exclude_record_id param (#191) |
| Throughput | `useBatchApproveSchedule` shipped but no UX surfaced it | `/bulk-review` (#192) |
| Affiliate | Bootstrap script crashed on its own availability check | Fix `available` property call (#194) |

The unifying rule the session codified: **every infrastructure mechanism
that produces output should also have a corresponding mechanism that
detects + removes its dead outputs.** Tomorrow's operator deploys this
runbook → all 10 PRs land → those 9 mechanisms come online → the
autonomous-feedback loop has materially less friction at every layer.

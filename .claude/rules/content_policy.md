# Content Policy Rules

## Never Generate
- Harmful medical, legal, or financial advice
- Content targeting minors
- Explicit or sexual content
- Misleading health claims
- Unverified claims presented as fact

## Always Include Disclaimers For
- Predictions/forecasts ("Experts predict...", "This could mean...")
- Unconfirmed reports ("Reports suggest...", "Unconfirmed:")
- Opinion pieces (clearly label as opinion/analysis)
- Experimental features ("Early access", "Beta")

## Citation Requirements
- Primary sources required for factual claims
- Multiple sources for controversial topics
- "Reports suggest..." prefix for unverified claims
- Every `must_cite=true` claim must have ≥1 source URL

## Platform Content Standards
- Hooks must be accurate — no misleading clickbait
- All claims in blueprints must trace to source URLs
- Templates must respect platform constraints (slides, word counts, durations)
- High-risk claims are blocked by default (see each niche's `config/risk_rules.yaml`)

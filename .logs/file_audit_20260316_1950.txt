SECTION 2: FILE-BY-FILE REVIEW (high-risk packages)

--- learning/ ---

arm_loader.py
  Purpose: Generic SharePoint bandit arm CRUD (alpha/beta parameters per niche).
  Issues:
    - save_arm() always calls proxy.create() -- never proxy.update(). This means
      if the same arm already exists in SharePoint, calling save_arm() again will
      create a duplicate row rather than update the existing one. Used by
      apply_warm_start() in meta_prior.py.
    - BANDIT_LIST_NAMES maps "ai_creators" but this is not a consistent key --
      trending_video_fetcher uses "ai_news" and video_content_writer also uses
      "ai_news". See niche_id inconsistency section.
  Coverage: tests/test_arm_loader.py -- exists.

reward_shaper.py
  Purpose: Two classes for computing bandit rewards: RewardShaper (simpler,
           per-platform weighted sum) and MonetisationRewardShaper (proximity
           boosting, WelfordNormalizer, SP live data).
  Issues:
    - There are TWO separate reward shaper classes in the same file with
      overlapping names. metric_collector.py imports and uses RewardShaper
      (the simpler one), but MonetisationRewardShaper is the more complete class
      with threshold boosting. The full threshold-boost logic never fires in
      production metric collection.
    - _fetch_youtube() returns "views", "likes", "comments" -- no completion_rate
      or engagement_rate. MonetisationRewardShaper.compute() expects completion_rate
      and engagement_rate; these are always 0.0 for YouTube. Rewards near-zero.
    - WelfordNormalizer returns 0.5 for first 10 samples -- bandit learning is
      blind for approximately the first two weeks.
  Coverage: tests/test_reward_shaper.py -- exists.

hook_classifier.py
  Purpose: XGBoost hook quality predictor, returns 0.5 when unavailable.
  Issues:
    - XGBClassifier instantiated with use_label_encoder=False (deprecated in
      xgboost >=2.0). Will raise TypeError on train_and_save() if newer xgboost
      is installed.
    - Model path resolves to genlab-core/models/ -- no persistence strategy for
      trained models (not .gitignored but not committed either).
  Coverage: tests/test_hook_classifier.py -- exists.

metric_collector.py
  Purpose: Prefect flow for collecting post-publish metrics at timed windows.
  Issues:
    - P1 BUG: _fetch_youtube() reads YOUTUBE_REFRESH_TOKEN (global) not per-niche
      OAuth tokens (e.g., CRITICALRUSH_YOUTUBE_REFRESH_TOKEN). CriticalRush YouTube
      metrics are fetched with BB credentials which may not have access to CR channel.
    - P1 BUG: _fetch_instagram() uses META_ACCESS_TOKEN (global). Same cross-channel
      credential problem.
    - P1 BUG: _fetch_facebook() uses FB_PAGE_ACCESS_TOKEN (global). Same problem.
    - compute_reward() uses RewardShaper (simpler class), not MonetisationRewardShaper.
      Production rewards are not monetisation-aware.
    - No retry logic for transient API failures beyond the Prefect retries=1 wrapper.
      A transient 429 permanently loses the window metrics.
  Coverage: tests/learning/test_metric_collector.py and tests/test_metric_collector.py.

config_writer.py
  Purpose: Atomic YAML write-back for schedule and template ratios.
  Issues:
    - update_schedule_from_bandit() always resets schedule slot minutes to ":00",
      silently losing any non-zero minute offsets (e.g., "12:30" becomes "12:00").
  Coverage: tests/test_config_writer.py -- exists.

config_update_flow.py
  Purpose: Weekly Prefect flow to apply bandit-learned config changes.
  Issues:
    - P1 BUG (line 161): calls backlog_client.get_items(store.LIST_NAME, ...).
      BacklogClient has NO get_items() method. PendingFeedbackStore has NO
      LIST_NAME attribute. This raises AttributeError at runtime. The entire
      weekly config learning loop is broken.
    - P1 BUG (line 78): compute_optimal_hours() uses t.published_at.hour (UTC),
      but schedule configs use IST (UTC+5:30). Optimal hour recommendations are
      offset by 5.5 hours from reality.
    - PendingFeedbackStore._from_sharepoint_item() is a private method called
      externally at line 172 (PendingFeedbackStore._from_sharepoint_item(item)).
  Coverage: NO test file for config_update_flow.py. Only test_config_updater.py
            which tests ConfigUpdater (a different class).

config_updater.py
  Purpose: Translate bandit learning into conservative YAML config changes.
  Issues:
    - _write_yaml_key() creates .bak backup but does NOT use atomic write (tmp+rename).
      Crashes during write would corrupt the YAML. config_writer.py uses atomic writes;
      inconsistent safety guarantees.
    - Docstring says "change < CHANGE_THRESHOLD (10%)" but the schedule comparison
      is in hours (clock_diff < 2.4 hours), not in reward units. Misleading.
  Coverage: tests/learning/test_config_updater.py -- exists.

meta_prior.py
  Purpose: Warm-start transfer of bandit priors from established to new niches.
  Issues:
    - apply_warm_start() uses next(iter(transfers)) -- deterministic today but
      fragile if TRANSFER_MATRIX gains multiple sources per target.
    - Observation check (t_a - 1) + (t_b - 1) > 2.0 may incorrectly classify
      an already-warm-started arm as having real observations due to exploration
      inflation (0.5 per parameter), allowing re-overwrite on second warm-start.
  Coverage: tests/test_meta_prior.py -- exists.


--- publishing/ ---

niche_credentials.py
  Purpose: Per-niche credential resolution with cross-channel guard.
  Issues:
    - resolve_meta_credentials() uses global_var="META_IG_USER_ID" but
      niche_suffix="IG_USER_ID". For non-BB niches this looks for
      e.g. CLUTCHWIRE_IG_USER_ID, not CLUTCHWIRE_META_IG_USER_ID. Inconsistent
      naming between global and niche suffix for IG user IDs.
    - No prefix for "ai_news" or "ai_tech" aliases; they silently resolve as
      global (BB) credentials rather than raising an error.
  Coverage: No dedicated test file found for niche_credentials.py.

scheduling.py
  Purpose: is_due() and build_caption() shared utilities.
  Issues:
    - build_caption(): if source_suffix is very long, body_limit = max_length -
      len(source_suffix) could be very small or negative. full[:negative_number]
      returns "" silently. No guard for this edge case.
  Coverage: No dedicated test file found for scheduling.py.

cdn_upload.py
  Purpose: Resolve local video file to public URL via Cloudflare tunnel.
  Issues:
    - cleanup() deletes all files ending with _{original_name} in serve_dir.
      If two uploads have the same original filename (e.g., output.mp4), cleanup
      deletes ALL matching files including any still-active CDN URLs.
    - LocalCDNUpload.__init__() raises ValueError if CLOUDFLARE_TUNNEL_URL not
      set. This crashes the Threads publishing flow entirely rather than skipping
      gracefully.
  Coverage: No test file found for cdn_upload.py.

analytics_recorder.py
  Purpose: Write publish records to Publishing_Analytics.
  Issues: Silent debug-only log when proxy is None -- should be WARNING.
  Coverage: tests/publishing/test_analytics_recorder.py -- exists.
